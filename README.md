## DESKRIPSI
Todo List Semester 3 adalah website sederhana yang dibuat untuk membantu pengguna mencatat, mengatur, dan mengelola berbagai tugas maupun kegiatan selama semester 3. Pengguna dapat menambahkan todo baru dengan judul dan keterangan, kemudian todo akan langsung ditampilkan pada halaman tanpa perlu melakukan refresh. Setiap todo dapat ditandai sebagai selesai menggunakan checkbox, diedit untuk mengubah informasi tugas, atau dihapus ketika sudah tidak diperlukan. Website ini juga dilengkapi dengan fitur Light Mode dan Dark Mode untuk memberikan tampilan yang lebih nyaman bagi pengguna. Project ini dibuat menggunakan HTML, CSS, dan JavaScript.
